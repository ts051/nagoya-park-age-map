# Radius Note Map

地図上をクリックして地点を登録し、指定した半径の円とテキストメモを表示する静的Webアプリです。

## 起動

```powershell
cd radius-note-map
npm install
npm run dev
```

表示されたURLをブラウザで開きます。登録内容はブラウザの `localStorage` に保存されます。

## 主な操作

- 地図をクリックして地点を選択
- 地点名、半径（10〜50,000m）、メモを入力して登録
- 地点ごとに地点名の常時表示・非表示を選択
- 登録地点のマーカーをクリックして編集
- 登録済みの半径円内をクリックして新しい地点を登録
- 一覧から地点へ移動、個別削除、全削除

公園・人口など、元アプリ固有のデータは使用していません。
